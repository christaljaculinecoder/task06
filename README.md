## ✅ 1 — Looping Through an Array

### 🎯 Goal

Create an array and print all values using four different loops:

- **for loop**
- **forEach**
- **for...of**
- **for...in**

### 📌 Sample Data

**const numbers = [10, 20, 30, 40];**

### 📝 Instructions

Print each value using all four looping methods.

### ✅ Expected Output

**10**  
**20**  
**30**  
**40**

### 📚 Concepts Practiced

- JavaScript Arrays
- `for` loop
- `forEach`
- `for...of`
- `for...in`
